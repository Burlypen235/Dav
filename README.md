# Student Test Generator

A lightweight web app for teachers, tutors, and students to quickly generate test papers across all levels of study:

- Primary School
- Middle School
- High School
- Undergraduate
- Postgraduate

## Features

- Select study level, subject, and topic
- Configure number of questions and difficulty blend
- Auto-generate question sets tailored to level
- Optional answer key guide
- Copy generated test to clipboard
- Download as `.txt`

## Run

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.
