# Dav

## TeacherTube Studio app

This repository contains a simple static app/landing page for a teaching YouTube
channel. It includes a hero section, workflow cards, and a checklist with a
small bit of JavaScript interactivity.

### How to use this code

1. Open the app locally in one of these ways:
   - Double-click `index.html` to open it directly in your browser, or
   - Serve it from a local web server (recommended if you plan to add more JS).

2. If you want to run a local server, you can use Python:

   ```bash
   python -m http.server 8000
   ```

3. Visit the app in your browser:

   ```
   http://localhost:8000/index.html
   ```

### Project files

- `index.html` — page structure and content.
- `styles.css` — visual styling and layout.
- `app.js` — checklist progress and button text updates.
